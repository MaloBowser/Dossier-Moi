# Textes Markdown du Dossier Moi

Chaque rubrique du site possède son propre dossier :

- `recits/contenu.md`
- `souvenirs/` : un fichier par lieu de la carte
- `evaluation/contenu.md`
- `projets/contenu.md`
- `affrontement/contenu.md`
- `reverie/contenu.md`
- `conclusion/contenu.md`

Enregistre simplement le fichier après avoir écrit. Recharge ensuite la page correspondante dans le navigateur pour voir le texte mis en forme.
